# Campus Navigation Robot
## Goal-Based Agent using Python

## Description
Campus Navigation Robot is a Goal-Based Agent that helps a robot reach a specified destination inside a college campus.

The agent continues taking actions until the required goal state is achieved.

## Agent Type
Goal-Based Agent

## Working
The agent:
- Receives a destination as the goal.
- Compares the current location with the goal.
- Moves until the destination is reached.

## Features
- Goal-oriented decision making
- Destination tracking
- Interactive navigation simulation

## Technology Used
- Python 3

## Learning Outcome
