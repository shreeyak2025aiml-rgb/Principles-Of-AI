# Smart Classroom Light Controller
## Simple Reflex Agent using Python

## Project Description
The Smart Classroom Light Controller is an implementation of a Simple Reflex Agent. The agent makes decisions based only on the current environmental condition (student presence).

The system checks whether students are present in a classroom and automatically controls the classroom lights.

## Agent Type
Simple Reflex Agent

## How It Works
- The agent receives a percept (student presence status).
- It applies predefined rules.
- It performs an action based on the current percept.

### Rules:
| Condition | Action |
|-----------|--------|
| Students Present | Turn Lights ON |
| No Students Present | Turn Lights OFF |

## Features
- Real-time user input
- Rule-based decision making
- Automatic classroom lighting control

## Technologies Used
- Python 3
