# Smart Classroom Allocation System
## Utility-Based Agent using Python

## Description
Smart Classroom Allocation System is a Utility-Based Agent that selects the best classroom by comparing utility scores.

The agent evaluates different options and chooses the one that provides maximum benefit.

## Agent Type
Utility-Based Agent

## Working
The agent:
- Assigns utility values to classrooms.
- Compares available choices.
- Selects the classroom with the highest utility score.

## Features
- Utility-based decision making
- Best option selection
- Performance optimization

## Technology Used
- Python 3
