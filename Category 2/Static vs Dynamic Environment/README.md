# Static vs Dynamic Environment

## Description

This project demonstrates the difference between Static and Dynamic environments using a Smart Parking Management System.

In a Static environment, the parking status remains unchanged during decision making.

In a Dynamic environment, the parking availability changes continuously over time.

## Features

- Parking slot monitoring
- Dynamic updates
- Real-time simulation
- Python implementation

## Technologies Used

- Python 3

## File Name

```
static_vs_dynamic.py
```

## Learning Outcome

This project demonstrates how intelligent agents operate in environments that either remain constant or change while decisions are being made.
