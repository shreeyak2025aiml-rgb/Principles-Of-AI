# Discrete vs Continuous Environment

## Description

This project demonstrates the difference between Discrete and Continuous environments using a Temperature Monitoring System.

In a Discrete environment, values are represented using predefined categories.

In a Continuous environment, values are represented using real numerical measurements.

## Features

- Temperature monitoring
- Discrete and continuous values
- Interactive execution
- Python implementation

## Technologies Used

- Python 3

## File Name

```
discrete_vs_continuous.py
```

## Learning Outcome

This project demonstrates the difference between discrete state spaces and continuous state spaces in Artificial Intelligence.
