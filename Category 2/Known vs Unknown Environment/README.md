# Known vs Unknown Environment

## Description

This project demonstrates the difference between Known and Unknown environments using a Campus Delivery Robot.

In a Known environment, the robot follows a predefined route to reach the destination.

In an Unknown environment, the robot explores different locations until it discovers the destination.

## Features

- Route planning
- Environment exploration
- Interactive simulation
- Python implementation

## Technologies Used

- Python 3

## File Name

```
known_vs_unknown.py
```

## Learning Outcome

This project demonstrates how intelligent agents behave when complete knowledge of the environment is available versus when they must explore unknown surroundings.
