# Episodic vs Sequential Environment

## Description

This project demonstrates the difference between Episodic and Sequential environments using a Student Performance Evaluation System.

In an Episodic environment, each decision is independent of previous events.

In a Sequential environment, each decision depends on previous actions and influences future outcomes.

## Features

- Student performance evaluation
- Independent and sequential decision making
- Interactive execution
- Python implementation

## Technologies Used

- Python 3

## File Name

```
episodic_vs_sequential.py
```

## Learning Outcome

This project demonstrates how intelligent agents make decisions independently in episodic tasks and how previous actions affect future decisions in sequential tasks.
