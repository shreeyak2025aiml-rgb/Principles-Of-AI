# Fully Observable vs Partially Observable Environment

## Description

This project demonstrates the difference between Fully Observable and Partially Observable environments using a Smart Campus Security System.

In a Fully Observable environment, the agent can view the status of every location before making a decision.

In a Partially Observable environment, the agent has access to only limited information and can observe only one location.

## Features

- Smart campus monitoring
- Full and partial observation
- Interactive user input
- Python implementation

## Technologies Used

- Python 3

## File Name

```
fully_vs_partially_observable.py
```

## Learning Outcome

This project helps understand how the amount of available information affects an intelligent agent's decision-making process.
