# Deterministic vs Stochastic Environment

## Description

This project demonstrates the difference between Deterministic and Stochastic environments using an Exam Eligibility System.

In a Deterministic environment, the same input always produces the same result.

In a Stochastic environment, random events influence the outcome.

## Features

- Predictable decision making
- Random event simulation
- Eligibility checking
- Python implementation

## Technologies Used

- Python 3

## File Name

```
deterministic_vs_stochastic.py
```

## Learning Outcome

This project helps understand the difference between predictable environments and environments involving uncertainty.
